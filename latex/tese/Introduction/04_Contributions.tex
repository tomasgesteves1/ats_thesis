\section{Contributions}
\label{sec:intro_contributions}

% What does this work contribute?
The main contributions of this work are the following.
\begin{itemize}
    \item Control-oriented models of the simulated \gls{usv} and \gls{uav} for real-time predictive control.
    \item Two cooperating \gls{nmpc} controllers, one for each vehicle, which track their references with an accuracy of a few centimetres, also under wind, and exchange their predicted trajectories, so that each anticipates the motion of the other and the tether is kept within its reach, whatever reference they are given.
    \item A simulation environment of the tethered system at sea.
    \item A set of useful manoeuvres and missions for the tethered system.
    \item The software of the system, publicly available at \url{https://github.com/tomasgesteves1/tethered-usv-uav-nmpc}.
\end{itemize}
